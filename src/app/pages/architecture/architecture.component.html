Architecture

One backbone, two deliverables

Task 1 (editor) and Task 2 (search) share the same architectural discipline: separated layers, decoupled events, Firebase isolated behind interfaces. What follows is pulled from the two projects’ real handover documents, not a summary written after the fact.

Presentation Views (MonoBehaviour) → Controllers (pure C#)
↓ raw events
Application Orchestration services, Commands / CommandHistory
↓
Domain Models (POCO), Ports (interfaces) — zero UnityEngine
↑ implements the Ports
Infrastructure Firebase REST client, AssetCache, ThumbnailRenderer, serializer
Core EventBus · ServiceLocator · AppLogger · FirebaseConfig
Bootstrap Composition root — the only assembly referencing everything
